## Limits

- The 62 KiB catalog regression budget is a conservative local guard below a
  rejected payload, not a claimed universal WebMCP protocol limit. No deployed
  origin was tested here.
- Artifacts are bounded to 32 files / 64 MiB per page. Jobs retain at most 50 IDs,
  with one wrapped job at a time. Reload discards both; no cancellation or durable
  cross-reload idempotency is offered.
- Project import validates before an additive in-memory commit, then requires a
  separate storage flush. It is not a cross-store database transaction.
- Engine files were retrieved, not run inside Phaser or other engines. This pass
  made no new paid generation calls. Concurrent animation work has separate evidence.
